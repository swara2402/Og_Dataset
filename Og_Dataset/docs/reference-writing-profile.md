# Academic reference-writing profile

This profile describes broad quality preferences for academic and technical documents. It is not a template for replacing an author's voice.

- Prefer clear, direct sentences and familiar discipline-appropriate vocabulary.
- Retain technical terminology, named entities, measurements, citations, and uncertainty.
- Allow sentence length and paragraph structure to vary when the argument benefits from it.
- Avoid decorative transitions, inflated wording, filler, and needless synonym variation.
- Preserve the author's intended emphasis and level of detail.
- Treat every supplied revision pair as evidence for review, not as a universal transformation rule.

The name AgriSense may appear in legacy examples elsewhere in this project; it is a named entity and must not be altered when present in source material.
